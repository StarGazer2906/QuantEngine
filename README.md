# QuantEngine

QuantEngine is a modular quantitative finance library developed from first principles while studying mathematical finance, stochastic calculus, numerical methods, and quantitative risk modelling.

The objective is to build a research-oriented pricing and risk engine covering equity, fixed income, FX, commodity and credit derivatives using modern C++ and Python.

---

## Project Vision

The goal is to implement, validate and document quantitative models used throughout the financial industry, ranging from classical analytical models to modern machine learning approaches.

Every model is accompanied by:

- Mathematical derivation
- Numerical implementation
- Calibration algorithms
- Pricing routines
- Greeks and risk sensitivities
- Validation against analytical or benchmark results
- Documentation and examples
